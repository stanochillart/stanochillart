# StanoChillArt

Robím si Android aplikácie hlavne **pre seba**.

Iné appky prídu s reklamami, chýbajúcimi funkciami a notifikáciami, ktoré chcú riadiť deň. Tak som si spravil vlastné. Čisté. Bez reklám. Bez sledovania. Offline, keď to dáva zmysel.

Ak ti niektorá sadne, vezmi si ju. Ak nie, nič sa nedeje.

---
